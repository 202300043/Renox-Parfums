# ARK: Survival Evolved - Landing Page

Landing page temática sobre el videojuego ARK: Survival Evolved, creada como proyecto educativo usando Vite, Tailwind CSS y TypeScript.

## Descripción

Página web responsive que presenta información sobre el videojuego ARK: Survival Evolved, incluyendo secciones sobre criaturas, mapas y características del juego.

## 🎮 Características

- **Diseño responsive** adaptado a móvil, tablet y escritorio
- **Animaciones interactivas** con JavaScript vanilla
- **Contador animado** en estadísticas del juego
- **Formulario de contacto** con validación
- **Menú responsive** con smooth scroll
- **Efectos de scroll** en header y elementos
- **Tema oscuro** inspirado en la estética del juego

## 🚀 Tecnologías

- Vite 7.1
- Tailwind CSS 4.1
- TypeScript 5.9
- Lucide Icons
